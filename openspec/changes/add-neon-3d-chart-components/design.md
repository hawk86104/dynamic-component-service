## Context

现有服务用 TresJS 承载 Three.js 对象，通过 `dcsConfig.ts` 自动发布 federation 模块。参考图一为不同高度的玻璃质感环形扇区；图二为沿 Z 轴分离的平滑面积实体，具有蓝青至黄绿/珊瑚色顶面。

## Goals / Non-Goals

**Goals:** 两个可独立使用的组件；JSON 驱动数据；几何、渐变和标签可调；环图突出玻璃反射与磨砂质感，面积图保留底座控制；与现有预览及导出机制一致。

**Non-Goals:** 不创建 Canvas/相机/灯光或改动通用视图；不依赖远程资产、后处理或第三方图表库；不实现悬浮交互与实时流式动画。

## Decisions

- 环图以数值决定角度；高度可按值缩放、统一高度，或由每项可选 `height` 指定。使用圆角挤出扇环而不是同心圆柱，保留真实侧壁和空心结构。
- 面积带以 `categories` + `series[].values` 描述等距分类轴；所有序列共享 Y 轴尺度。单调三次插值避免 Catmull-Rom 在局部峰值处过冲或低于零；`smooth: false` 使用折线。每条序列为封闭实体，支持单点数据与全零数据。
- JSON 支持既有 JSON5 编辑器；维持上一次有效数据，语法或语义错误通过 `data-error` 事件和公开 `dataError` 返回，成功后清空。支持直接更新 `jsonText` 和已有的 `jsonTextChangeNumber` 刷新协议。
- 公共工具只处理数据校验、底座/标签/轮廓与资源释放。两套 shader 分别位于组件同名目录，环图沿高度着色，结合世界方向的程序化柔光箱反射、Fresnel 透明度、厚度着色及经过像素覆盖衰减的细微磨砂；面积图沿 X 轴三色渐变。高光无需 Bloom、外部环境贴图或宿主灯光也可显示；不采样场景画面，不声称实现真实折射。
- 环图倒角几何合并同位置顶点并重新计算平滑法线，使条形反射连续；透明模式采用双面前后两次绘制和较弱背面着色，呈现内外壁层次，不写入深度。`opacity=1` 时切换单面与深度写入，保留完全不透明模式。shader 接入对数深度以适配宿主。
- 标签使用世界空间 Sprite/CanvasTexture，图表本体为真实 mesh。环图不再调用共享底座工具，移除底座四项参数，扇区底部位于局部 y=0；面积图保留可关闭的底座/背板/网格。环图通过 `reflectionStrength` 调反光、`roughness` 调反射模糊和磨砂，降低默认不透明度以强化通透层次。几何和材质只在参数改变时重建，清理旧资源；不持续占用渲染循环。
- 输入上限为 32 个扇区、8 条序列和 128 个分类；校验有限数值、非负数据、同长序列及十六进制色值，限制细分数和尺寸，避免异常输入拖垮页面。

## Risks / Trade-offs

- [透明面排序受视角影响] → 使用封闭实体、合理透明度及独立轮廓，允许调至不透明。
- [大量标签重叠] → 标签可关闭；环图使用径向外置标签与引导线，面积图仅标注峰值。
- [无后处理时辉光范围有限] → 用明亮轮廓和 Fresnel 高光实现基础风格，宿主可自行接入 Bloom。
- [当前任务不允许运行构建/浏览器] → 执行定向 lint、数据与几何测试，明确区分未运行的视觉验证。

## Migration Plan

新增文件与两个注册条目即可接入；无依赖、存量数据迁移。回滚删除新增资源和注册项。
