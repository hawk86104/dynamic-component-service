## Context
参考是 WebGPU/TSL 独立场景；本库使用 TresMesh 和 CustomShaderMaterial，不能移植场景相机灯光。

## Goals / Non-Goals
Goals：指定原图、红金玫红衍射、五角星、两行文字、双面镜像和可配置参数。
Non-Goals：不复制整个 WebGPU 场景，不承诺原参考完整波动光学数值一致性。

## Decisions
使用 MeshBasicMaterial 的 CustomShaderMaterial 合成图像、衍射和文字，独立顶点/片元文件，兼容已有渲染与对数深度处理。以光栅节距和视角计算波长，红色滤镜压低绿蓝光。五角星使用十顶点边界而非四向星芒。单一 DoubleSide 平面保留 UV，背面自然镜像，避免不透明背板遮挡。
原图作为打包资源导入，保持 941:1672 比例。文字独立透明 CanvasTexture，定位于原图 x=155、基线 y=1427/1505；白色在镭射之后合成。仅文字变化重绘，卸载清理纹理和材质。

## Risks / Trade-offs
字体平台差异 → 系统中文字体栈及测量适配。超长文字 → 缩小至最小字号后省略。图片加载失败 → 发出 error 事件并保留红色底卡。未经视觉验证 → 遵循用户规则仅做 lint 与源码检查，明确报告。

## 圆角与星芒流动扩展
在片元中以卡宽为单位做圆角矩形距离裁剪，保证纵横圆角半径相同。星芒遍历相邻九格，中心抖动扩大至格宽的 94%，独立随机缩放和旋转，避免跨格星形截断。使用 useLoop 的 delta 积分动画速度，驱动星芒平移与亮度变化；速度为零冻结相位，改速不跳变。背景和文字 UV 保持固定。

## 运动粒子拖尾扩展
沿用模型粒子器的 PointsMaterial + CustomShaderMaterial、柔光点精灵、寿命渐变和加法混合。卡片仅采样圆角轮廓，不在内部表面生成粒子。轮廓密度控制边缘采样，粒子密度控制整体抽样，拖尾密度控制每个发射点的轨迹点数。
保存最多 256 个世界矩阵时间样本（约 30 Hz），每帧重采样为 32 个历史矩阵并乘当前世界逆矩阵，将历史轨迹转换为当前局部空间。shader 按粒子寿命插值历史位置，因此平移、父级变换及原地旋转均有响应，避免固定风向以及重复施加父级变换。长度控制历史回看窗口（长度 / 3 秒），幅度缩放当前点与历史点之间的位移；粒子速度控制沿轨迹的推进频率。
静止时持续向四周及正反面散发红系粒子；运动历史叠加到基础扩散，停止后运动历史自然耗尽但基础扩散继续。采用固定容量环形缓冲，初始化及长时间挂起后重置历史，奇异变换时隐藏拖尾。参数中不暴露手动方位角、俯仰角或轴偏移。只在尺寸、圆角或密度改变时重建几何，材质参数即时同步。资源由组件卸载清理。

配置面板增加通用可选 group 字段，将十项参数归入“红系粒子拖尾”；未设置 group 的已有配置保持原有布局，不修改通用预览 Vue 文件。

## 静止粒子可见性修正
移除片元透明度对运动距离的依赖。以卡片归一化位置确定向外方向，随机角度扰动及正负法向分量保证正反面粒子均可见，避免所有粒子与卡面共面。基础扩散距离随卡宽、拖尾长度、寿命和幅度变化，继续受粒子速度、透明度与扰动参数控制，不增加配置项。

## 深红边缘粒子调整
默认值按用户当前配置归整浮点尾差后同步到共享 defaults。渐变改为 #a61924 / #780b18 / #3c0410，使用普通透明混合并移除亮芯增益，防止叠加变白变黄。移除卡面内部采样，只从圆角边界发射；shader 按当前卡片圆角距离遮掉落入内部的粒子中心，避免转动历史轨迹穿过卡片内部时叠加。

## 粒子配色调试
新增渐变开关、纯色与三段渐变色选择器。默认保留当前深红渐变，关闭渐变时三段 uniform 使用同一纯色。修改颜色仅同步材质 uniform，不重建粒子或重置历史；输入非法十六进制颜色时回退对应默认色。

## 自然扩散与预览变换调试
默认粒子密度从 0.1 提升至 0.4，拖尾密度从 0.6 提升至 0.8，共 4047 个粒子；默认扰动 0.85。每个粒子独立种子和分层随机寿命偏移，使用连续时间的一维平滑随机噪声驱动三个方向，避免同一发射点共用固定周期轨迹。粒子速度为零继续冻结相位，扰动为零关闭随机位移；无需每帧重建几何。

由于现有配置仅能修改组件参数，新增 createPreviewTransform 作为预览层通用可选基础设施，由 templateComponet 调用，dcsConfig 仅对献花卡片启用 previewTransform。位置三轴、旋转三轴（度）、等比大小及重置保存在当前实例响应状态中，变换施加到原组件根节点，供世界历史正确采样。未启用组件保留初始变换；调试状态不进入 defaults、配置复制或发布组件依赖。面板随现有 pane 一起销毁。
## 场景变换控制器修订
预览变换改用 @tresjs/cientos 的 Three.js TransformControls，附着于预览包装组，直接拖动移动、旋转及缩放手柄。移除 XYZ 和大小数值输入，仅保留工具切换、世界/局部空间和重置。变换组包含卡片，世界矩阵历史继续响应父级变换。previewEntry 将 OrbitControls 注册为默认控制器，TransformControls 拖动事件自动暂停/恢复它，避免同时转动相机。控制器随预览卸载释放，外部组件不依赖预览模块。
