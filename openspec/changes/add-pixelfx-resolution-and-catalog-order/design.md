## Context

PixelFX 按上游固定像素网格模拟。四种呈现类型共用一张 Canvas 贴图。全部组件页面按注册顺序展示条目。

## Goals

- 放大时提供可选的平滑贴图，缺省值沿用原始采样。
- 全部组件列表先展示其他组件，PixelFX 作为一组显示在末尾。

## Decisions

- 原生帧继续按上游网格绘制。选择 2× 或 4× 时，用支持透明度的 Canvas 平滑插值生成对应尺寸的贴图，再使用线性采样。复用画布和纹理对象，切换尺寸时让渲染器重新分配贴图存储。尺寸与播放状态彼此独立。
- 将 `dcsConfig.components` 中的 PixelFX 条目组移到末尾。目录沿用注册顺序，并按当前分类和关键词过滤。

## Risks / Trade-offs

- 平滑贴图以原生帧为输入。2× 与 4× 分别增加到四倍和十六倍的贴图像素数。
