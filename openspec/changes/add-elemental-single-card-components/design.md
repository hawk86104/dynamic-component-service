## Context

参考视频通过胶囊卡片、外围元素特效及渐变光泽建立视觉识别。用户明确要求四个独立单卡组件，效果存在于宿主三维场景中。项目使用 Vue / TresJS / Three.js，已有组件服务注册和远程发布流程。

## Goals / Non-Goals

**Goals:**
- 四个独立入口：`emberElementalCardComponent`、`solarElementalCardComponent`、`breezeElementalCardComponent`、`bloomElementalCardComponent`。
- 有厚度、倒角的胶囊实体、可定制文字与颜色、独立三维特效、暂停/启用/重播及根节点访问。
- 所有入口共享基础卡片与生命周期，特效分别实现；参数面板、组件默认值与文档保持一致。

**Non-Goals:**
- 轮播、卡组管理、独立页面相机和全场景后处理。
- 物理流体求解或整场景镜面反射；局部光晕不冒充实时倒影。

## Decisions

1. **组合式运行时**：共享基础胶囊几何、文字纹理、轮廓光、地面光晕和粒子工具；入口传入专用特效工厂。每个实例独立持有材质、纹理、动画时钟与随机种子。
2. **真实空间结构**：火焰使用本地包围盒中的程序化三维噪声 ray marching；太阳使用围绕胶囊轮廓的三维光束；风使用前后穿行的曲带；花瓣使用多层参数曲面并计算法线。常规透明材质启用深度测试、关闭深度写入，卡片实体承担遮挡。
3. **局部自发光**：将光晕与细亮轮廓直接建成局部几何，保证不依赖宿主 Bloom。使用线性色彩和 Three.js 颜色空间转换，支持 log-depth 和裁剪 Shader chunks。
4. **参数更新与资源所有权**：颜色、速度、强度更新 uniform；尺寸或拓扑改变重建所属资源，旧资源立即释放。文字更新复用 CanvasTexture，异步字体完成后仅在实例存活时重绘。
5. **公开接口**：`play`、`pause`、`restart`、`setEnabled`、`getObject3D`；可读写参数保持为 Vue props，通过 `update:enabled`、`update:playing` 同步控制状态。
6. **预览接入**：所有注册、默认参数、控件和说明写入 `dcsConfig.ts`，静态 SVG 明确作为示意封面，不修改通用预览文件。

## Risks / Trade-offs

- 透明花瓣与交叠光束存在排序风险 → 花瓣使用独立网格与实际几何中心，深度测试保留；不设置全场景强制渲染顺序。
- 火焰采样成本随分辨率增加 → 提供采样步数与粒子数量，限制最大值，暂停时不推进时间。
- 参考是正面录屏，无法证明任意视角的原始实现 → 提供三维深度并保留后续真实 GPU 观感检查，不宣称像素级或性能验收。
- 构建/浏览器验证受项目规则约束 → 执行类型、定向 lint、CPU 几何/生命周期检查、OpenSpec 和 diff 检查，记录 GPU 未验证。

## Migration Plan

新增文件后注册四个组件。无依赖迁移、无旧配置迁移。回滚时移除对应注册和专用资源。

## Open Questions

无阻塞问题；最终 GPU 观感、宿主透明排序和帧率留待用户明确授权调试。

## Ember 逐帧修订

2026-10-26 用户要求先单独精修 Ember。检查 1080p、30 fps 原片 n=0–29、300–359、435–509，共 165 帧，包括两次激活、稳定燃烧与离开过程。上一版单锥体 FBM 的发射位置、宽高比及粒子类型不符合画面。

- 火焰从胶囊上半圆和两肩形成弧形火冠，最亮的白热层贴着上缘。外焰红，顶端形成多股交替卷曲的细火舌；不使用从卡片中心向上的单个实心锥。
- 参考稳定段火冠宽度约为卡宽的 1.3–1.6 倍，卡片上方火焰约为卡高的 0.3–0.5 倍。这些是视觉估计范围，非 GPU 验收结果。
- 实现分为浅体积火冠、具有实际纵深的参数化火舌、红色燃烧轮廓与专用火星。火星主要集中在上缘，少量沿整圈漂浮，混入空心三角。
- 特效工厂允许提供自有轮廓及粒子系统。默认路径保持现有行为，只有 Ember 使用这些能力。
- 火冠和火舌共享局部时间、速度、尺寸和种子，帧间连续变化；不加载视频帧贴图，不根据相机固定成全屏特效。

## Solar 逐帧修订

本轮仅精修 Solar，沿用变更 `add-elemental-single-card-components`。已连续检查 n=36–80、210–254、360–449，共 180 帧。原片先亮起轮廓，随后展开短刺、长光束与柔光。稳定段暖白日冕完整连续，光束从卡心方向向外展开，空心环和细光点缓慢向外漂移。

- 复用上一轮已有的工厂自有轮廓、粒子、局部时钟接口，Solar 实现独立日冕与粒子系统，不调整其他组件的渲染路径。
- 精确求解极角方向与胶囊轮廓的交点，光束沿卡心到交点的方向发散，保留前后纵深。短、中、长束分别抽样，叠加细亮核心与渐宽低亮度柔光。
- 日冕采用有厚度的闭合曲管，分为暖白核心、近场金色辉光和外层柔光；宽度通过 uniform 调整，不重建几何。
- 帧间变化以轻微伸缩和亮度闪动为主，光束角度保持稳定；粒子沿原始方向向外运动，空心环独立绘制。
- 继续执行类型、lint、CPU 和 OpenSpec 检查；用户上一轮已明确暂不运行，故不启动构建、预览或浏览器，也不把静态检查当作视觉验收。
