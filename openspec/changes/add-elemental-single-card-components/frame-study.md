## 关键形态

1. 发射源为胶囊上半圆与两肩。原片最亮处贴着弧形上缘，上半圈外形成一层火冠。
2. 稳定火冠宽度约为卡宽的 1.3–1.6 倍，伸出卡片顶部的可见火焰约为卡高的 0.3–0.5 倍。这是画面的估计范围，不是运行截图测量所得的实现验收值。
3. 火焰根部呈暖白色，向外变为明红、深红，再消散。外焰能看出细长、交叠和局部镂空的条带，不是一个充满噪声的实心锥体。
4. 火舌变形的方向主要向上，左右有弯曲；不同火舌高度和相位不同，不能靠整体周期缩放模拟。
5. 上缘有密集细小白热点，夹杂稀疏空心三角。卡片两侧和底部也有少量慢速余烬，不能只在卡片中心垂直喷粒子。
6. 卡片下半圈轮廓偏红，上缘明亮。现有通用偏金色轮廓不适合直接用于 Ember。

## 对应调整

- `ember/profile.ts`：以卡宽为比例单位，从实际上半圆和两肩确定火冠空间包围范围。
- `flame.frag`：弧形发射约束、浅体积层、向上输运的各向异性噪声、暖白根部和红色外焰。
- `ember/tongues.ts` 与 `tongue.vert/.frag`：两层具有实际纵深的火舌，分别设置根部、宽度、高度和相位，向上弯曲并用噪声侵蚀边缘。
- `rim.vert/.frag`：Ember 单独的红色沿边燃烧，上半圈向暖白过渡，替代该实例的通用轮廓。
- `ember/sparks.ts` 与 `sparks.vert/.frag`：上半圈火星、少量沿边余烬、空心三角；图形由片元 Shader 绘制。
- 工厂提供可选轮廓、粒子和局部时钟配置，仅 Ember 启用。Solar、Breeze、Bloom 使用原有路径。

类型、定向 lint 和 CPU 检查通过，含上半圆根部、前后纵深、参数一致性、连续调速、速度零冻结、拓扑变化保留相位、资源释放及四种组件回归。

用户明确选择“暂不运行，保留代码修改”。因此未启动预览、未进行浏览器调试或运行截图对照，也不把以上静态结果表述为已达到高还原度。实际火焰形态、曝光和运动节奏仍待用户授权后在 GPU 中逐帧比较。
