# Solar 逐帧观察与实现依据

参考：[元素卡片原视频](https://x.com/kaolti/status/2110322552841056689/video/1)。本轮仅精修 Solar，分析使用 1440×1080、30 fps 版本。组件不包含原视频帧或卡片截图贴图，视觉由三维几何和 Shader 重建。

## 检查片段

连续检查 n=36–80、210–254、360–449，共 180 帧，帧号从 0 开始。时间为 n/30。

| 帧段 | 观察 |
| --- | --- |
| 36–47，1.2–1.567 秒 | 初次激活；暖白轮廓先亮起，短光刺逐渐拉长，长束随后显现。 |
| 48–68，1.6–2.267 秒 | 稳定日冕，长短束和柔光层次清楚；稀疏光环出现在轮廓外。 |
| 69–80，2.3–2.667 秒 | 卡片离开，光束跟随卡片，后续逐步变弱。 |
| 210–222，7–7.4 秒 | 再次进入、轮廓亮起、光束伸展。 |
| 223–250，7.433–8.333 秒 | 稳定放射场；各束独立明暗变化，空心环缓慢外移。 |
| 251–254，8.367–8.467 秒 | 卡片离开。 |
| 360–364，12–12.133 秒 | 第三次激活和展开。 |
| 365–433，12.167–14.433 秒 | 较长稳定段，便于观察角度、微弱伸缩、亮度波动和光环轨迹。 |
| 434–449，14.467–14.967 秒 | 卡片离开，光环和光束逐渐消散。 |

## 关键形态

1. 日冕是一圈完整、较亮的暖白轮廓，外侧有近场金辉；核心亮边不是一组断开的尖刺。
2. 卡片两侧的光束也有向上/向下的分量，整体呈从卡心向外展开的放射方向。直接沿直边法线发射会出现过多平行水平束。
3. 存在密集近场细刺、较清晰的中长亮束，以及渐宽、低透明度的柔光。长度、宽度和亮度均有差异。
4. 稳定段光束角度基本不变，主要是独立闪动和轻微伸缩；整体没有明显旋转。
5. 细小白金色光点集中在日冕附近，混有稀疏、大小不一的空心圆环，圆环缓慢向外移动。
6. Solar 表面以暖金、杏色为主，顶部有浅绿高光。n=390 的六处内侧小区采样均值约为 `#d89676`、`#c7d090`、`#bd7d3f`、`#d19e5c`、`#c58b37`、`#d4a261`。这些是视频曝光、叠光后的颜色，只用于指导配色倾向，不直接等同于着色器参数或已完成的视觉对比。

## 对应调整

- `solar/geometry.ts` 精确求极角射线与胶囊边界的交点，使束根沿整个轮廓分布，平面方向与卡心连线一致；带独立前后纵深。
- 主体光束按短、中、长三类分级，叠加两倍数量的近场细刺。亮束和柔光共用发射数据，但宽度与透明度分别计算。
- `corona.vert/.frag` 实现有厚度的闭合日冕，分暖白核心、近场金辉、外层柔光；宽度和亮度通过 uniform 更新。
- `solar/particles.ts`、`motes.vert/.frag` 实现独立光点和空心环，沿固定发射方向外移。
- `solarSpeed` 使用上一轮已有的局部时钟接口，变速连续、速度零冻结、结构重建保留相位。
- 日冕宽度、亮度、光束纵深、柔光、独立速度、空心环占比和外移范围已接入 props、默认值与配置面板。
