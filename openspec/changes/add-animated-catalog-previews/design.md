## Context

目录由 `dcsConfig.components` 驱动，包含共享元素卡片注册。真实演示路由为 `#/preview/:type`。本次用户明确要求对每个组件重新录制，包括原 GIF，并指定 600×400，优先于录制技能的默认分辨率和 GIF 保留约定。

## Goals / Non-Goals

目标：44 个真实预览、600×400、约 10 帧、压缩体积、默认静止、悬停按需加载且无空白闪烁。

范围：目录展示与资源采集。组件逻辑、默认参数、发布机制及通用三维预览文件保持原实现。

## Decisions

1. 每个组件使用 `<type>.webp` 动图与 `<type>.poster.webp` 首帧，注册项显式提供 `previewPath` 和 `previewPosterPath`。独立封面避免为了提取第一帧先下载完整动画。
2. 独立目录图片组件始终保留封面 DOM。只有指针进入图片区域才挂载动图，真实 load 事件后才显示；移出、取消指针、页面隐藏和卸载均终止动画展示。失败时继续展示封面。
3. 使用现有浏览器受控 CDP 通道，不启动服务或另建浏览器驱动。900×600 工作视口统一缩小为 600×400。按真实页面状态、资源完成情况、加载占位是否消失、场景可渲染节点及截图共同确认就绪。桌面合成截图存在秒级延迟，因此通过 Tres 已完成 render 的回调直接读取真实 WebGL canvas；记录实际采样时序，不修改动画时间。采样时保持专用标签页前台，避免后台节流。
4. 录制标签页临时隐藏参数面板、说明、网格、坐标及变换工具。调整现有相机以完整显示主体；静态对象通过轻微往返视角展示立体形态。三项会飞出视野的发射特效使用固定偏移的跟随相机，保留原生运动。关闭标签页即清除临时状态。
5. 每段保留原始 PNG 和采集时序。离线编码检查实际尺寸、帧数、时长、循环、重复帧和大小，并生成解码联系表。异常条目重试；未验收资源不得替换注册地址。
6. 首帧直接提取 WebP 首个 ANMF 的压缩帧载荷，导出普通静态 WebP；回读像素与动图第一帧完全一致，避免二次压缩或下载完整动图后才提取首帧。聚能光球采集完整周期共 12 帧，编码器合并相邻相同画面后为 11 帧，保留原播放时长。
7. 模型粒子器的原模型响应缺少跨域许可，浏览器确认 `MissingAllowOriginHeader`。采集使用相同 GLB 的临时本地副本，记录来源与原因；副本位于忽略的 `.cache/preview-capture/`，不改源模型地址。人头组件必须等待 `GNM Head Loading` 节点消失后重录。

## Risks / Trade-offs

- 10 帧适合轻量预览，快速粒子和复杂瞬态效果需要挑选代表性片段。
- 远程模型、视频或贴图可能失败；记录并重试真实资源，不生成替代效果。
- 旧 SVG/GIF/PNG/JPG 在新资源验收后按后续要求删除，回滚须从 Git 同时还原原文件和配置；动图和小封面由按需加载控制访问成本。

## Validation

逐项解码与联系表视觉验收，目录首次请求及悬停/离开/失败交互检查，必要的源码静态 lint 与 diff 检查。本次不执行构建或服务启动。
